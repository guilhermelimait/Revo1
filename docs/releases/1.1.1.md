# Revo1 1.1.1

A small update that keeps the interface readable and animated pictures looking right.

## Fixed

- **Complete tab labels:** Settings and Screensaver tabs now account for keyboard
  focus borders, so the final label is no longer cropped. Checked in Light and
  Dark mode at four display scales.
- **Clean transparent GIFs and pictures:** transparent pixels are composited over
  black before conversion. Hidden palette colours no longer appear as coloured
  patches or leftover shapes on the knob.

## Updating

Install the new Windows app over your existing installation. Preferences,
Bluetooth pairing and your collection are preserved.

**For media imported before this fix:** remove the affected picture or GIF,
import the original file again, then send the collection to the knob. Existing
converted files cannot recover transparency from their JPEG frames.

No firmware update is needed if your knob already runs 1.1.0. Matching 1.1.1
firmware is also included for new installations.

## Downloads

- **Windows x64:** `Revo1-Setup-1.1.1.exe`
- **Windows ARM64:** `Revo1-Setup-1.1.1-arm64.exe`
- **Round display:** `revo1-firmware-1.1.1.bin`
- **Integrity checks:** `SHA256SUMS-1.1.1.txt`

The installers are not code-signed; Windows SmartScreen may show a warning.
